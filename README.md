# 💻 Laptop Price Prediction

An interactive **Laptop Price Prediction** application built using **Python, Scikit-learn, and Tkinter**.  
This project predicts laptop prices based on key specifications like **RAM, SSD/HDD, CPU/GPU, touchscreen, and OS**.

---

## 🔹 Features

- **Machine Learning Model:** Linear Regression with feature engineering for accurate predictions.  
- **Interactive GUI:** Built with Tkinter, allowing users to input laptop specifications.  
- **Sliders:** Adjust RAM, HDD, and SSD easily.  
- **Toggle Buttons:** Select Yes/No for Touchscreen and IPS.  
- **Live Prediction Display:** Shows predicted price on the screen instantly.  
- **Reset Functionality:** Clears all inputs to default values.

---

## 🛠 Tech Stack

- Python 3.x  
- Scikit-learn  
- Pandas & Numpy  
- Tkinter for GUI
